Stickman Studio

Внутренний инструмент YouTube-канала «Невыдумка» · Internal tool of the YouTube channel “Невыдумка”

Stickman Studio — это личное настольное приложение владельца YouTube-канала «Невыдумка» (@nevydumka.animation). Оно помогает владельцу канала загружать собственные видео в приватном режиме, отвечать на комментарии под своими видео и смотреть статистику своего канала через YouTube Data API и YouTube Analytics API.

Приложение работает только на компьютере владельца канала и не предназначено для других пользователей.

Stickman Studio is a personal desktop application used by the owner of the YouTube channel Невыдумка (@nevydumka.animation). It lets the channel owner upload their own videos as private, reply to comments on their own videos, and view their own channel statistics using the YouTube Data API and the YouTube Analytics API.

The app runs only on the channel owner's computer and is not offered to other users.
