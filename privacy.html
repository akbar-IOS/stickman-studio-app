Privacy Policy

Stickman Studio · Last updated: November 13, 2026

Stickman Studio (“the app”) is a personal desktop application used only by the owner of the YouTube channel Невыдумка to manage that channel. This policy explains what data the app accesses and how it is handled.

Data the app accesses

When the channel owner signs in with Google, the app requests access to the owner's own YouTube account through the YouTube Data API and the YouTube Analytics API:

  • Read access to the channel's videos, comments and statistics (youtube.readonly, yt-analytics.readonly).
  • Uploading the owner's own videos as private (youtube.upload).
  • Replying to and moderating comments on the owner's own videos (youtube.force-ssl).

How data is used and stored

  • Data is used only to provide these functions to the channel owner: uploads, comment management, and analytics reports.
  • OAuth tokens are stored only in the macOS Keychain on the owner's computer. Channel statistics and comments are stored only in local files on that computer.
  • The app has no server. No data is sent to the developer or to any third party, and no data is sold, shared, or used for advertising.
  • Stickman Studio's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at Google Account permissions or via Google security settings. Deleting the app's local files and Keychain entries removes all stored data.
